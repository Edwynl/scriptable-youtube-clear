# Scriptable YouTube Clear

在 iPhone 的 [Scriptable](https://scriptable.app) 里打开 m.youtube.com，并注入一段脚本，让网页版 YouTube 更好用：

- 左侧悬浮面板：搜索 / 返回 / 首页
- 搜索弹窗：实时搜索建议 + 本地最近搜索记录
- 隐藏广告位，自动跳过或快进视频广告
- 锁屏 / 后台继续播放，锁屏界面和控制中心的媒体控制
- 横屏时自动进入全屏，自动点掉“仍在观看？”弹窗
- 偏好 1080p 画质

测试机型：iPhone 14 Pro Max

## 安装

1. 在 Scriptable 里新建脚本，把 `YouTubeClear.js` 的全部内容粘贴进去。
2. 必须在 **App 内运行**：在快捷指令里添加 Scriptable 的 “Run Script” 动作，并打开 **Run In App / 在 App 中运行**，再把快捷指令添加到主屏幕。
   - 不要用普通的扩展模式运行，也不要用快捷指令的小窗 WebView，否则脚本会提示并退出。

## 调试面板

在屏幕**左上角 1.6 秒内连点 4 下**会打开调试面板，再点 4 下关闭。第一行显示：

| 字段 | 含义 |
|---|---|
| `fs` | 视频是否处于 iOS 原生全屏 / 画中画 |
| `hidden` | 页面是否真的在后台（绕过脚本自己的可见性伪装） |
| `userPaused` | 是否被记为“用户手动暂停” |
| `inAd` | 是否正在播放广告 |

## 版本记录

### v1.5.0

**修复：全屏时无法暂停**
iOS 全屏用的是系统原生播放器，点暂停时网页收不到触摸事件，旧版把它当成“后台自动暂停”立即恢复播放。现在全屏 / 画中画里的暂停会检查页面的真实可见性：页面在前台就当作用户暂停；全屏时锁屏（暂停后 800ms 内进入后台）仍会继续播放。

**其他改进**
- 横屏自动全屏只在“竖屏 → 横屏”时触发一次，且只在播放页触发（旧版每 300ms 触发，横屏时无法退出全屏）
- 横屏隐藏顶栏 / 面板改用 CSS 媒体查询
- 强制 HD 不再每 300ms 轮询，只在开始播放时设置
- 广告结束后恢复用户原来的静音和倍速（旧版强制改回 1x 并取消静音）
- “仍在观看？”弹窗改为按弹窗文字匹配，每 2 秒检查一次，用 `textContent` 代替 `innerText`
- 移除多余的 MutationObserver
- 搜索建议请求带序号，丢弃晚到的旧结果
- `destroy()` 完整还原所有补丁和监听器，重复注入不会层层叠加
- 视频自然播完时不再强制重播
- 整页刷新后自动重新注入（每 3 秒检查一次）

### v1.4.0

初始版本。

## 测试

`tests/` 里用 jsdom 模拟 iOS 播放器行为（原生全屏暂停、系统暂停、锁屏、画中画）：

```bash
cd tests
npm install
npm test                                   # 测试当前版本
node pause-scenarios.mjs 某个旧版本.js      # 测试指定文件
```

| 场景 | 期望 | v1.4.0 | v1.5.0 |
|---|---|---|---|
| 全屏里点暂停 | 暂停 | ❌ | ✅ |
| 非全屏时被系统暂停（切后台） | 继续播放 | ✅ | ✅ |
| 全屏时锁屏 | 继续播放 | ✅ | ✅ |
| 全屏暂停后再点播放 | 播放 | ✅ | ✅ |
| 全屏暂停一会儿后再锁屏 | 保持暂停 | ❌ | ✅ |
| 画中画里点暂停（App 在后台） | 暂停 | ❌ | ✅ |

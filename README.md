# Scriptable YouTube Clear

在 iPhone 的 [Scriptable](https://scriptable.app) 里打开 m.youtube.com，并注入一段脚本，让网页版 YouTube 更好用：

- 左侧悬浮面板：搜索 / 返回 / 首页
- 搜索弹窗：实时搜索建议 + 本地最近搜索记录
- 隐藏广告位，自动跳过或快进视频广告，广告后恢复原来的倍速和静音
- 锁屏 / 后台继续播放，锁屏界面和控制中心的媒体控制
- 横屏时自动进入全屏，自动点掉“仍在观看？”弹窗
- 偏好 1080p 画质

测试机型：iPhone 14 Pro Max

## 安装

1. 在 Scriptable 里新建脚本，把 `YouTubeClear.js` 的全部内容粘贴进去。
2. 必须在 **App 内运行**：在快捷指令里添加 Scriptable 的 “Run Script” 动作，并打开 **Run In App / 在 App 中运行**，再把快捷指令添加到主屏幕。
   - 不要用普通的扩展模式运行，也不要用快捷指令的小窗 WebView，否则脚本会提示并退出。

## 暂停是怎么判断的

脚本要同时做到两件事：**切后台时系统造成的暂停要自动恢复**（后台播放），**用户的暂停要尊重**。难点是 iOS 原生全屏、画中画、拔耳机、来电造成的暂停，网页都收不到触摸事件，看起来和“系统暂停”一样。v1.6.0 的规则：

| 暂停发生时 | 处理 |
|---|---|
| 刚有触摸 / 锁屏控制中心点了暂停 | 用户暂停 |
| 画中画里 | 用户暂停（画中画本来就是后台用的） |
| 原生全屏里，页面在前台 | 先当作用户暂停；1 秒内页面真的进入后台（锁屏）→ 撤销并恢复 |
| 内联播放，页面在前台 | 先当作暂停（拔耳机、来电）；1 秒内进入后台 → 撤销并恢复 |
| 页面已在后台 | 系统暂停 → 自动恢复 |
| YouTube 自己在后台调用 `pause()` | 拦截 |

“1 秒内进入后台就撤销”是为了处理一个时序问题：切后台时，系统的暂停有时比后台事件早到几十毫秒。

## 调试面板

在屏幕**左上角 1.6 秒内连点 4 下**打开，再点 4 下关闭。第一行：

| 字段 | 含义 |
|---|---|
| `fs` | 视频是否在 iOS 原生全屏 / 画中画 |
| `hidden` | 页面是否真的在后台（绕过脚本自己的可见性伪装） |
| `bg` | 脚本是否认为已切到后台 |
| `userPaused` | 是否被记为用户暂停（不会自动恢复） |
| `inAd` | 是否正在播放广告 |
| `keepAlive` | 保活音频是否在运行 |

## 版本记录

### v1.6.0：合并 Claude v1.5.0 与 Codex v1.5.0

以 Claude 版为基础，吸收 Codex 版的优点，并修复两个版本都有的问题。

**两个版本都有的问题（本版新修）**
- 前台被系统暂停（拔耳机、来电）后，之后一锁屏视频就自己开始播放（外放）
- 监听 `window` 的 blur 用了捕获模式，会收到输入框等元素的失焦，被误判为切后台；还会拦截页面上所有元素的 blur 事件
- `visibilitychange` 在回到前台时也会触发，旧版把它也当成了切后台

**来自 Codex 版**
- 只在真正处于后台时拦截 `pause()`；前台的暂停一律尊重（旧版前台也会拦截）
- 进入全屏时的 blur 不算切后台，全屏开始时重置后台状态
- 锁屏“下一个”只点击一次（旧版会点两次，可能连跳两个视频）
- 每个锁屏动作单独注册，某个动作不被支持时不影响其他动作
- 锁屏进度条随每次循环更新
- 用户暂停后停止保活音频省电（本版改为暂停超过 10 分钟才停，短暂停仍能从锁屏直接继续）
- 广告和 UI 修复合并进一个主循环，去掉单独的 300ms 定时器
- 广告期间不设置画质
- 搜索框：关闭自动大写和拼写检查，外接键盘 Esc 关闭
- 侧边按钮加 `role` 和 `aria-label`，旁白可读
- `'use strict'`、搜索建议空值保护、返回首页的兜底跳转

**保留 Claude 版的做法（Codex 版这几处有问题）**
- 画中画里的暂停当作用户暂停（Codex 版会自动恢复）
- 全屏时锁屏仍然后台续播（Codex 版会停住）
- 横屏自动全屏只在转为横屏时触发一次，只在播放页（Codex 版退出全屏后会被拉回，首页预览视频也会全屏）
- 广告中途切换视频时不重置广告状态（Codex 版会让下个视频停在 16 倍速静音）
- 广告结束只撤销我们设置的 16 倍速，恢复的是正片时的倍速和静音
- “仍在观看？”弹窗按弹窗文字匹配，2 秒检查一次，用 `textContent`
- 原生方法只保存一次、监听器统一登记，`destroy()` 完整还原
- 整页刷新后自动重新注入

**未采用**
- Codex 版开启了锁屏 ±10 秒快退快进：iOS 会因此把锁屏的“上一个 / 下一个”换成 ±10 秒按钮，所以保持关闭
- Codex 版拖动锁屏进度条会同时开始播放：本版暂停中拖动保持暂停

### v1.5.0

修复全屏时无法暂停；横屏全屏只触发一次；强制 HD 不再轮询；广告后恢复静音和倍速；弹窗检测降频；搜索建议丢弃过期结果；`destroy()` 完整还原；整页刷新后自动重新注入。

### v1.4.0

初始版本。
